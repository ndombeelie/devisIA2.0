## Démarrage

### 1. Lancer l'application

**Windows :**
- Double-cliquez sur l'icône **DevisAI Desktop** sur votre bureau
- Ou recherchez "DevisAI" dans le menu Démarrer

### 2. Se connecter

```

## Créer une entreprise

Après connexion, vous devez créer votre entreprise.

### Étape 1 : Accéder à la page

```
┌─────────────────────────────────────┐
│  + Nouvelle entreprise              │
└─────────────────────────────────────┘
```

### Étape 2 : Remplir les informations

| Champ | Description | Exemple |
|-------|-------------|---------|
| **Nom** * | Nom de votre entreprise | "Tech Solutions SARL" |
| **Adresse** | Adresse complète | "123, Av. de la Paix, Kinshasa" |
| **Téléphone** | Numéro de téléphone | "+243 81 234 5678" |
| **Email** | Email professionnel | "contact@techsolutions.cd" |

### Types de produits

| Type | Utilisation | Exemples |
|------|-------------|----------|
| **Produit** | Marchandise physique | Ordinateur, vêtement, nourriture |
| **Service** | Prestation intellectuelle | Consultation, formation, développement |

### Unités disponibles

- **Unité** : Pour les articles simples
- **Heure** : Pour les prestations horaires
- **Jour** : Pour les tarifs journaliers
- **m²** : Pour les surfaces
- **m** : Pour les longueurs
- **kg** : Pour les poids
- **Forfait** : Pour les packages

└─────────────────────────────────────────────────────────────────┘
```

### Étapes de création

#### 1. Sélectionner le client

Choisissez un client dans la liste déroulante.

#### 2. Ajouter des lignes

Pour chaque ligne :
1. Sélectionnez un **produit** ou entrez une description manuelle
2. Modifiez la **quantité**
3. Ajustez le **prix** si nécessaire
4. Vérifiez la **TVA**
5. Ajoutez une **remise** si nécessaire

#### 3. Ajouter des lignes supplémentaires

Cliquez sur **+ Ajouter une ligne** pour chaque nouvel article.

#### 4. Vérifier les totaux

Les calculs sont automatiques :
- **Sous-total HT** : Somme des lignes
- **TVA** : Calculée selon les taux
- **Total TTC** : Montant final

#### 5. Ajouter des notes (optionnel)

```
Notes :
┌─────────────────────────────────────────────────────┐
│ Livraison prévue dans 15 jours ouvrables.          │
│ Un acompte de 30% est demandé au début du projet.  │
└─────────────────────────────────────────────────────┘

Conditions générales :
┌─────────────────────────────────────────────────────┐
│ 1. Ce devis est valable 30 jours.                  │
│ 2. Le paiement s'effectue en 2 fois :              │
│    - 50% à la commande                             │
│    - 50% à la livraison                            │
│ 3. Les modifications feront l'objet d'un nouveau   │
│    devis.                                          │
└─────────────────────────────────────────────────────┘
```

#### 6. Sauvegarder

Cliquez sur **💾 Enregistrer le devis**.

### Modifier le statut

| Statut | Quand l'utiliser ? |
|--------|-------------------|
| Brouillon | En cours de rédaction |
| Envoyé | Envoyé au client |
| Accepté | Validé par le client |
| Refusé | Rejeté par le client |

## Convertir en facture

### Condition préalable

Le devis doit avoir le statut **"Accepté"**.

### Procédure

1. Allez dans **📄 Devis**
2. Trouvez le devis accepté (badge vert)
3. Cliquez sur le bouton **Facturer** (vert)

```
┌─────────────────────────────────────────────────────┐
│  Devis #DEV-2026-00001                              │
│  Entreprise ABC SARL                                │
│  Total : 2 111,20 USD                               │
│  Statut : ✅ Accepté                                │
│                                                     │
│  [ Voir ]  [ 🧾 Facturer ]  [ Supprimer ]          │
└─────────────────────────────────────────────────────┘
```

4. Confirmez la conversion

```
┌─────────────────────────────────────┐
│  Convertir ce devis en facture ?    │
│                                     │
│  [ Annuler ]    [ Confirmer ]       │
└─────────────────────────────────────┘
```

5. La facture est créée avec un nouveau numéro (ex: FAC-2026-00001)

### Ce qui est copié

- ✅ Client
- ✅ Articles
- ✅ Totaux
- ✅ Notes

### Ce qui est nouveau

- 🆕 Numéro de facture
- 🆕 Date de facture
- 🆕 État : "En attente"

## Sauvegarder les données

### Exporter

1. Allez dans **📁 Sauvegardes**
2. Choisissez le format :
   - **JSON** : Universel et lisible
   - **SQLite** : Copie exacte de la base

```
┌─────────────────────────────────────────────────────┐
│  SAUVEGARDES                                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  📤 Exporter les données                            │
│                                                     │
│  [ 📥 Exporter en JSON ]                            │
│                                                     │
│  [ 🗄️ Exporter la base SQLite ]                     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

3. Sélectionnez l'emplacement
4. Cliquez sur **Sauvegarder**

### Importer

1. Allez dans **📁 Sauvegardes**
2. Cliquez sur **📂 Sélectionner un fichier**
3. Choisissez votre fichier JSON
4. Les données sont restaurées

> ⚠️ **Attention** : L'import remplace toutes les données existantes !

## Conseils pratiques

### 💡 Gagner du temps

1. **Créez vos produits à l'avance** : Ils seront disponibles dans les devis
2. **Utilisez les catégories** : Pour organiser vos produits
3. **Configurez l'IA** : Pour des devis générés automatiquement
4. **Exportez régulièrement** : Pour éviter la perte de données
